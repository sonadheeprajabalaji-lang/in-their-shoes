# in-their-shoes

## Pixel art (Chapter 1)

The Chapter 1 room is drawn at runtime by `Assets/Scripts/PixelArtSkin.cs`. It installs itself when the scene loads, so nothing needs to be set up in the scene.

- Sprites: `Assets/Resources/PixelArt` (32 px per grid cell, point filtering, no compression).
- Sprites are generated by `Tools/pixel_art/generate_sprites.py` (Python + Pillow). Edit and re-run it to change the art, then copy `out/*.png` over the files in `Assets/Resources/PixelArt`.
- Font: Pixelify Sans (SIL Open Font License, see `Assets/Resources/PixelArt/Fonts`).
- To turn the skin off, set `PixelArtSkin.AutoInstall = false`.
