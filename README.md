# in-their-shoes

## Pixel art (Chapters 1 and 2)

Each chapter's room is drawn at runtime by `Assets/Scripts/PixelArtSkin.cs`. It installs itself whenever a chapter scene loads (including via Next Chapter), so nothing needs to be set up in the scene. Each chapter's room, furniture, task art and mood overlay is listed in `ArtByChapter` in that script; a chapter with no entry keeps its placeholder squares.

- Sprites: `Assets/Resources/PixelArt` (32 px per grid cell, point filtering, no compression).
- Sprites are generated by `Tools/pixel_art/generate_sprites.py` (Chapter 1) and `generate_sprites_ch2.py` (Chapter 2, which also re-runs the first). Python + Pillow. Edit and re-run, then copy `out/*.png` over the files in `Assets/Resources/PixelArt`.
- To add a chapter: draw its room and task sprites, then add an entry to `ArtByChapter` with its task ids, hold-task art and furniture cells.
- Font: Pixelify Sans (SIL Open Font License, see `Assets/Resources/PixelArt/Fonts`).
- To turn the skin off, set `PixelArtSkin.AutoInstall = false`.
