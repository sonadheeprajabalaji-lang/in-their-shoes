# in-their-shoes

## Pixel art (Chapters 1 to 6)

Each chapter's room is drawn at runtime by `Assets/Scripts/PixelArtSkin.cs`. It installs itself whenever a chapter scene loads (including via Next Chapter), so nothing needs to be set up in the scene. Each chapter's room, furniture, task art and mood overlay is listed in `ArtByChapter` in that script; a chapter with no entry keeps its placeholder squares.

- Sprites: `Assets/Resources/PixelArt` (32 px per grid cell, point filtering, no compression).
- Sprites are generated by `Tools/pixel_art/generate_sprites.py` (Chapter 1), `generate_sprites_ch2.py` (Chapter 2) and `generate_sprites_ch3to6.py` (Chapters 3 to 6). Each re-runs the ones before it, so running the last one regenerates everything. Python + Pillow. Edit and re-run, then copy `out/*.png` over the files in `Assets/Resources/PixelArt`.
- To add a chapter: draw its room and task sprites, then add an entry to `ArtByChapter` with its task ids, hold-task art and furniture cells.
- Font: Merriweather, regular and bold (SIL Open Font License, see `Assets/Resources/PixelArt/Fonts`).
- To turn the skin off, set `PixelArtSkin.AutoInstall = false`.

## Tutorial and chapter start screens

- `Assets/Scenes/Tutorial.unity` is the first scene in the build. `TutorialUI` builds one picture page at runtime (how to play on top, her four meters below) and then loads Chapter 1 on Enter. Keycaps light up when pressed, so players can try the keys.
- Each chapter's start screen (`MeterIntroUI`) shows the chapter title, the four meter icons, the main task and that chapter's prompt keys, read from the main task's `jugglePrompts`, so it always matches the scene.
- Keycaps and meter icons come from `Tools/pixel_art/generate_sprites_tutorial.py` (copy `out_tutorial/*.png` into `Assets/Resources/PixelArt`). Shared UI helpers are in `UIArt.cs`.
